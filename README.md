# 宙斯后台 · 首页运营看板原型

单文件 HTML 原型，v1.0 定稿（2026-10-17）。原生 JS + 本地 ECharts，**不依赖网络，离线可开**。

## 打开方式

仓库内直接打开 `index.html` 即可，需保证 `libs/echarts.min.js` 与它保持同目录关系。

```
admin-dashboard/
├── index.html              主页
├── libs/echarts.min.js     图表库（本地，离线可用）
├── PROTOTYPE-v1.md         定稿说明：模块结构 / 口径 / 配色规则
├── dashboard-home-2x.png   整页高清截图 3200×4226
└── README.md
```

## 包含模块

核心指标 · 活跃情况 · 席位构成 · 用户规模 · 续费日历 · 客户来源占比 · 菜单分析 · 数据认领 · 税票采集，右上角另有全局搜索与模块显隐面板。

## 数据说明

当前全部为原型造数，用于界面与交互评审，不作为业务结论。其中**已开通用户 230、总席位 440、MRR ¥76,000/月**等口径互相自洽，完整定义见 `PROTOTYPE-v1.md`。

## 交互要点

- 时间范围：近 7 天 / 近 1 个月 / 近半年 / 近一年
- 模块显隐状态保存在 localStorage，刷新不丢
- 支持 1600px 大屏到 414px 手机宽度
